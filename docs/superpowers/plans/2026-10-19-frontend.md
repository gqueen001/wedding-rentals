# Wedding Rentals Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the mobile-first Solid.js website for the v1 wedding-dress marketplace: public pages (home, dress list with filters, dress, shop, favorites) and the `/admin` panel. The site is in Turkmen, Russian and English, can be installed as a PWA, and runs on top of the existing Go API.

**Architecture:** One Vite + Solid single-page app lives in `frontend/`. npm installs the packages, because Deno's own npm client downloads full package metadata, which stalls on this network. Deno then runs everything from `node_modules`: Vite, tests and type checks (`"nodeModulesDir": "manual"`). All HTTP goes through `src/lib/api.ts` and `src/lib/upload.ts`. Client state lives in small, separately tested modules under `src/lib` and `src/i18n`: filters, favorites, paged lists, translations, auth and form mapping. Pages and components are checked with `deno check`, `vite build` and a browser pass against the running API. Admin pages are lazy-loaded so the public bundle stays small on slow mobile networks.

**Tech Stack:** Deno 2.4, Vite 7.3.7, solid-js 1.9.17, @solidjs/router 1.0.0, vite-plugin-solid 2.11.14, Tailwind CSS 4.3.3 (`@tailwindcss/vite`), @fontsource/forum 5.3.0, @fontsource-variable/manrope 5.3.0, and @std/assert 1.0.19 from JSR.

**Spec:** `docs/superpowers/specs/2026-10-18-wedding-rentals-v1-design.md`. §8 Frontend, §9 Error handling and §10 Testing apply here, and §7 API is the contract.

## Global Constraints

- **Location and tooling**
  - All frontend code lives under `frontend/`.
  - npm only installs packages: `cd frontend && npm install`.
  - Always run tools with `deno task <name>`. Never run Vite with Node: Node 20.12 here is too old for Vite 7.
- **Versions**
  - Pin every dependency to an exact version in `package.json`, with no `^` or `~`.
  - Vite stays on 7.3.7. Vite 8 calls `node:util.parseEnv`, which Deno 2.4.0 does not provide.
- **Languages**
  - The UI is in Turkmen (`tk`, the default), Russian (`ru`) and English (`en`).
  - The chosen language is stored in localStorage under `wr.lang`.
  - Every user-visible string comes from `src/i18n/{tk,ru,en}.json`. These are flat key files with identical key sets, which a test enforces.
  - The brand name is the `app.name` key.
- **Browser storage**
  - The localStorage keys are exactly `wr.lang`, `wr.favorites` and `wr.admin_token`.
  - All storage access goes through `src/lib/storage.ts`, which never throws.
- **Network:** only `src/lib/api.ts` (fetch) and `src/lib/upload.ts` (XMLHttpRequest) touch the network.
- **API contract**
  - Errors arrive as `{"error":{"code","message","fields?"}}`.
  - `per_page` is at most 60 and `ids` at most 100.
  - Enum slugs:
    - color: `white, ivory, champagne, blush, other`
    - silhouette (query parameter `style`): `ball_gown, a_line, mermaid, straight, short`
    - sleeves: `long, short, none`
    - sizes: `XS, S, M, L, XL, XXL`
- **Filter URLs:** `/dresses` keeps its filter state in the query string, using the keys `q, city, price_min, price_max, size, color, style, sleeves` in that order.
- **Visual system "Gyrmyzy" (chosen by the product owner)**
  - Color tokens are defined in `src/index.css` `@theme`:

    | Token | Hex | Use |
    |---|---|---|
    | white | `#FFFFFF` | page background |
    | veil | `#F4F2F5` | quiet surfaces and skeletons |
    | ink | `#241B27` | text |
    | garnet | `#8E1B2E` | primary color, prices, the ornament band |
    | garnet-deep | `#6B1222` | hover state |
    | silver | `#A7ACB4` | borders and ornament only, never text |
    | silver-ink | `#5D6370` | secondary text |
    | blush | `#F8E7EA` | selected and favorite states |

  - Fonts are Forum (display, weight 400 only) and Manrope Variable (all other text). Both are self-hosted through @fontsource: no Google Fonts and no external CDN, since those may be blocked in Turkmenistan.
  - The göl ornament band (`src/components/GolBand.tsx`) is the only decorative element. No drop shadows on content, no gradients, no all-caps labels, no "→" in link text, and layouts are left-aligned.
  - Radii follow a hierarchy: pill buttons, 0.5rem inputs, 2px photos.
- **Accessibility floor**
  - Every control is a real `button`, `a`, `input` or `select` with an accessible name.
  - Focus is visible as a 2px garnet outline.
  - `prefers-reduced-motion` turns transitions off.
  - Dress photos use the dress title as alt text. Dialogs trap Tab and close on Escape.
- **Layout:** mobile first. Dress grids have 2 columns under 640px, 3 at 640px and up, and 4 at 1024px and up. Content is at most 72rem wide (`max-w-6xl`), with 1rem side padding.
- **Development:** Vite runs on `:5173` and proxies `/api` and `/uploads` to `http://localhost:8080`.
- **Production:** `deno task build` writes `frontend/dist`. The Go server serves it (`WEB_DIR=../frontend/dist`) and injects Open Graph tags before `</head>` on `/dresses/:id`, so `index.html` must contain no `og:` tags of its own.
- **Checks:** `deno task test` (Deno.test with @std/assert, for `src/lib` and `src/i18n`) and `deno task check` (type-checks all of `src`) must both be clean before every commit.
- **Commits:** every commit message ends with the `Co-Authored-By:` trailer line the controller gives you.

`frontend/src/lib/storage.ts`:
```ts
/** A tiny key-value store that never throws (private mode, blocked storage, tests). */
export interface KV {
  get(key: string): string | null;
  set(key: string, value: string): void;
  remove(key: string): void;
}

export function memoryKV(initial: Record<string, string> = {}): KV {
  const m = new Map(Object.entries(initial));
  return {
    get: (k) => m.get(k) ?? null,
    set: (k, v) => void m.set(k, v),
    remove: (k) => void m.delete(k),
  };
}

function browserStorage(): Storage | null {
  try {
    return globalThis.localStorage ?? null;
  } catch {
    return null; // some browsers throw just for touching localStorage
  }
}

/** Wraps a Web Storage object and falls back to memory when it is missing or throws. */
export function safeKV(storage: Storage | null = browserStorage()): KV {
  const fallback = memoryKV();
  function attempt<T>(fn: (s: Storage) => T, alt: () => T): T {
    if (storage) {
      try {
        return fn(storage);
      } catch {
        // blocked or full: use memory for this page view
      }
    }
    return alt();
  }
  return {
    get: (k) => attempt((s) => s.getItem(k) ?? fallback.get(k), () => fallback.get(k)),
    set: (k, v) => attempt((s) => s.setItem(k, v), () => fallback.set(k, v)),
    remove: (k) => attempt((s) => s.removeItem(k), () => fallback.remove(k)),
  };
}
```

```ts
import type { CityRef, Lang } from "./types.ts";

/** Groups thousands with a no-break space: 12500 → "12 500". */
export function formatPrice(n: number): string {
  return Math.trunc(n).toString().replace(/\B(?=(\d{3})+(?!\d))/g, "\u00A0");
}

export function cityName(city: CityRef, lang: Lang): string {
  if (lang === "ru") return city.name_ru;
  if (lang === "en") return city.name_en;
  return city.name_tk;
}

/** Builds a tel: link from a phone typed by an admin, e.g. "+993 65 12-34-56". */
export function telHref(phone: string): string {
  return "tel:" + phone.replace(/(?!^\+)[^\d]/g, "");
}
```

```ts
import { type Accessor, createSignal } from "solid-js";
import en from "./en.json" with { type: "json" };
import ru from "./ru.json" with { type: "json" };
import tk from "./tk.json" with { type: "json" };
import { type KV, safeKV } from "../lib/storage.ts";
import type { Lang } from "../lib/types.ts";

export type MessageKey = keyof typeof en;
export type Params = Record<string, string | number>;

export const LANGS: readonly Lang[] = ["tk", "ru", "en"];
export const DEFAULT_LANG: Lang = "tk";
// The Record type makes `deno check` fail if tk or ru is missing a key.
export const dictionaries: Record<Lang, Record<MessageKey, string>> = { tk, ru, en };

const LANG_KEY = "wr.lang";

/** Looks key up in dict, then in English, then returns the key itself; fills {name} params. */
export function translate(dict: Partial<Record<string, string>>, key: string, params?: Params): string {
  const english: Partial<Record<string, string>> = dictionaries.en;
  const template = dict[key] ?? english[key] ?? key;
  if (!params) return template;
  return template.replace(/\{(\w+)\}/g, (match, name: string) => (name in params ? String(params[name]) : match));
}

export function isLang(v: unknown): v is Lang {
  return typeof v === "string" && (LANGS as readonly string[]).includes(v);
}

export interface I18n {
  lang: Accessor<Lang>;
  setLang(lang: Lang): void;
  t(key: MessageKey, params?: Params): string;
  /** For keys built at runtime, such as `error.${code}`. */
  tr(key: string, params?: Params): string;
}

export function createI18n(kv: KV): I18n {
  const stored = kv.get(LANG_KEY);
  const [lang, setLangSignal] = createSignal<Lang>(isLang(stored) ? stored : DEFAULT_LANG);
  const tr = (key: string, params?: Params) => translate(dictionaries[lang()], key, params);
  return {
    lang,
    setLang(next) {
      setLangSignal(next);
      kv.set(LANG_KEY, next);
      if (typeof document !== "undefined") document.documentElement.lang = next;
    },
    t: tr,
    tr,
  };
}

export const i18n = createI18n(safeKV());
export const t = i18n.t;
export const tr = i18n.tr;
```

```ts
export class ApiError extends Error {
  readonly status: number;
  readonly code: string;
  readonly fields: Record<string, string>;

  constructor(status: number, code: string, message: string, fields: Record<string, string> = {}) {
    super(message);
    this.name = "ApiError";
    this.status = status;
    this.code = code;
    this.fields = fields;
  }
}

interface ErrorBody {
  error?: { code?: string; message?: string; fields?: Record<string, string> };
}

/** Turns an error response body (or anything else) into an ApiError. */
export function toApiError(status: number, data: unknown, fallbackMessage: string): ApiError {
  const e = (data as ErrorBody | null)?.error;
  return new ApiError(status, e?.code ?? "internal_error", e?.message ?? fallbackMessage, e?.fields ?? {});
}

export interface ApiDeps {
  fetch: typeof fetch;
  token: () => string | null;
  onUnauthorized: () => void;
}

interface RequestOptions {
  body?: unknown;
  auth?: boolean;
}

function withQuery(path: string, query?: URLSearchParams): string {
  const qs = query?.toString() ?? "";
  return qs ? `${path}?${qs}` : path;
}

export function createApi(deps: ApiDeps) {
  async function request<T>(method: string, path: string, opts: RequestOptions = {}): Promise<T> {
    const headers: Record<string, string> = { Accept: "application/json" };
    if (opts.body !== undefined) headers["Content-Type"] = "application/json";
    if (opts.auth) {
      const token = deps.token();
      if (token) headers.Authorization = `Bearer ${token}`;
    }
    let res: Response;
    try {
      res = await deps.fetch(path, {
        method,
        headers,
        body: opts.body === undefined ? undefined : JSON.stringify(opts.body),
      });
    } catch {
      throw new ApiError(0, "network_error", "network request failed");
    }
    if (res.status === 204) return undefined as T;
    const data: unknown = await res.json().catch(() => null);
    if (!res.ok) {
      if (opts.auth && res.status === 401) deps.onUnauthorized();
      throw toApiError(res.status, data, res.statusText);
    }
    return data as T;
  }

  const admin = { auth: true } as const;

  return {
    cities: () => request<{ items: City[] }>("GET", "/api/cities").then((r) => r.items),
    dresses: (query?: URLSearchParams) => request<Page>("GET", withQuery("/api/dresses", query)),
    dress: (id: number | string) => request<PublicDress>("GET", `/api/dresses/${encodeURIComponent(String(id))}`),
    shop: (slug: string, query?: URLSearchParams) =>
      request<PublicShop>("GET", withQuery(`/api/shops/${encodeURIComponent(slug)}`, query)),
    login: (email: string, password: string) =>
      request<{ token: string }>("POST", "/api/admin/login", { body: { email, password } }).then((r) => r.token),
    admin: {
      shops: () => request<{ items: AdminShop[] }>("GET", "/api/admin/shops", admin).then((r) => r.items),
      shop: (id: number) => request<AdminShop>("GET", `/api/admin/shops/${id}`, admin),
      createShop: (input: ShopInput) => request<AdminShop>("POST", "/api/admin/shops", { ...admin, body: input }),
      updateShop: (id: number, input: ShopInput) =>
        request<AdminShop>("PUT", `/api/admin/shops/${id}`, { ...admin, body: input }),
      deleteShop: (id: number) => request<void>("DELETE", `/api/admin/shops/${id}`, admin),
      dresses: (shopId?: number) =>
        request<{ items: AdminDress[] }>(
          "GET",
          withQuery("/api/admin/dresses", shopId ? new URLSearchParams({ shop_id: String(shopId) }) : undefined),
          admin,
        ).then((r) => r.items),
      dress: (id: number) => request<AdminDress>("GET", `/api/admin/dresses/${id}`, admin),
      createDress: (input: DressInput) => request<AdminDress>("POST", "/api/admin/dresses", { ...admin, body: input }),
      updateDress: (id: number, input: DressInput) =>
        request<AdminDress>("PUT", `/api/admin/dresses/${id}`, { ...admin, body: input }),
      deleteDress: (id: number) => request<void>("DELETE", `/api/admin/dresses/${id}`, admin),
      reorderImages: (ids: number[]) => request<void>("PATCH", "/api/admin/images/order", { ...admin, body: { ids } }),
      deleteImage: (id: number) => request<void>("DELETE", `/api/admin/images/${id}`, admin),
    },
  };
}
```

```ts
import { ApiError, toApiError } from "./api.ts";
import type { Image } from "./types.ts";

export type UploadOwner = { listingId: number } | { shopId: number };

export interface UploadDeps {
  token: () => string | null;
  onUnauthorized: () => void;
}

/** Uploads one photo with XMLHttpRequest, because fetch cannot report upload progress. */
export function createUploader(deps: UploadDeps) {
  return function upload(file: File, owner: UploadOwner, onProgress: (fraction: number) => void): Promise<Image> {
    return new Promise((resolve, reject) => {
      const form = new FormData();
      form.append("file", file);
      if ("listingId" in owner) form.append("listing_id", String(owner.listingId));
      else form.append("shop_id", String(owner.shopId));

      const xhr = new XMLHttpRequest();
      xhr.open("POST", "/api/admin/images");
      const token = deps.token();
      if (token) xhr.setRequestHeader("Authorization", `Bearer ${token}`);
      xhr.upload.onprogress = (e) => {
        if (e.lengthComputable) onProgress(e.loaded / e.total);
      };
      xhr.onerror = () => reject(new ApiError(0, "network_error", "network request failed"));
      xhr.onload = () => {
        let data: unknown = null;
        try {
          data = JSON.parse(xhr.responseText);
        } catch {
          // not JSON, e.g. a proxy error page
        }
        if (xhr.status >= 200 && xhr.status < 300) {
          onProgress(1);
          resolve(data as Image);
          return;
        }
        if (xhr.status === 401) deps.onUnauthorized();
        reject(toApiError(xhr.status, data, xhr.statusText));
      };
      xhr.send(form);
    });
  };
}
```

```ts
import {
  type Color, COLORS, type Silhouette, SILHOUETTES, type Size, SIZES, type Sleeves, SLEEVES,
} from "./types.ts";

export interface Filters {
  q: string;
  city: string;
  priceMin: number | null;
  priceMax: number | null;
  size: Size | null;
  color: Color | null;
  style: Silhouette | null;
  sleeves: Sleeves | null;
}

export const EMPTY_FILTERS: Filters = {
  q: "", city: "", priceMin: null, priceMax: null, size: null, color: null, style: null, sleeves: null,
};

const MAX_PRICE = 2_147_483_647; // the API rejects anything above int4

function oneOf<T extends string>(allowed: readonly T[], v: string | null): T | null {
  return v !== null && (allowed as readonly string[]).includes(v) ? (v as T) : null;
}

function price(v: string | null): number | null {
  const s = v?.trim() ?? "";
  if (!/^\d+$/.test(s)) return null;
  const n = Number(s);
  return n <= MAX_PRICE ? n : null;
}

/** Reads filters from a URL query; unknown or invalid values are dropped. */
export function parseFilters(query: URLSearchParams): Filters {
  return {
    q: (query.get("q") ?? "").trim(),
    city: (query.get("city") ?? "").trim(),
    priceMin: price(query.get("price_min")),
    priceMax: price(query.get("price_max")),
    size: oneOf(SIZES, query.get("size")),
    color: oneOf(COLORS, query.get("color")),
    style: oneOf(SILHOUETTES, query.get("style")),
    sleeves: oneOf(SLEEVES, query.get("sleeves")),
  };
}

/** Writes filters as a query in a fixed key order, leaving out empty values. */
export function filtersToQuery(f: Filters): URLSearchParams {
  const query = new URLSearchParams();
  const put = (key: string, value: string | number | null) => {
    if (value !== null && value !== "") query.set(key, String(value));
  };
  put("q", f.q.trim());
  put("city", f.city);
  put("price_min", f.priceMin);
  put("price_max", f.priceMax);
  put("size", f.size);
  put("color", f.color);
  put("style", f.style);
  put("sleeves", f.sleeves);
  return query;
}

/** How many filters are set in the filter sheet; the search text is not counted. */
export function countActiveFilters(f: Filters): number {
  return [f.city || null, f.priceMin, f.priceMax, f.size, f.color, f.style, f.sleeves]
    .filter((v) => v !== null).length;
}
```

```ts
import { type Accessor, createSignal } from "solid-js";
import { type KV, safeKV } from "./storage.ts";

export const FAVORITES_KEY = "wr.favorites";
/** The API's per_page cap, so the favorites page loads them in one request. */
export const MAX_FAVORITES = 60;

function parse(raw: string | null): number[] {
  try {
    const value: unknown = JSON.parse(raw ?? "[]");
    if (Array.isArray(value)) {
      const ids = value.filter((n): n is number => Number.isSafeInteger(n) && n > 0);
      return [...new Set(ids)].slice(0, MAX_FAVORITES);
    }
  } catch {
    // corrupted value: start over
  }
  return [];
}

export interface Favorites {
  ids: Accessor<number[]>;
  has(id: number): boolean;
  toggle(id: number): void;
  /** Drops saved ids that are not in `existing` (deleted or unpublished dresses). */
  keepOnly(existing: readonly number[]): void;
}

export function createFavorites(kv: KV): Favorites {
  const [ids, setIds] = createSignal(parse(kv.get(FAVORITES_KEY)));
  const save = (next: number[]) => {
    setIds(next);
    kv.set(FAVORITES_KEY, JSON.stringify(next));
  };
  return {
    ids,
    has: (id) => ids().includes(id),
    toggle(id) {
      const current = ids();
      save(current.includes(id) ? current.filter((x) => x !== id) : [id, ...current].slice(0, MAX_FAVORITES));
    },
    keepOnly(existing) {
      const keep = new Set(existing);
      const next = ids().filter((id) => keep.has(id));
      if (next.length !== ids().length) save(next);
    },
  };
}
```

```ts
import { type Accessor, createSignal } from "solid-js";
import type { Page } from "./types.ts";

export interface PagedList<T> {
  items: Accessor<T[]>;
  total: Accessor<number>;
  loading: Accessor<boolean>;
  error: Accessor<unknown>;
  hasMore: () => boolean;
  /** Clears everything and loads page 1. */
  reset(): Promise<void>;
  /** Loads the next page unless one is loading, the last one failed, or there is none. */
  loadMore(): Promise<void>;
  /** Loads the page that failed. */
  retry(): Promise<void>;
}

/** Accumulates pages for infinite scroll; responses that arrive after a reset are ignored. */
export function createPagedList<T>(fetchPage: (page: number) => Promise<Page<T>>): PagedList<T> {
  const [items, setItems] = createSignal<T[]>([]);
  const [total, setTotal] = createSignal(0);
  const [loaded, setLoaded] = createSignal(0);
  const [loading, setLoading] = createSignal(false);
  const [error, setError] = createSignal<unknown>(null);
  let generation = 0;

  async function load(pageNumber: number) {
    const gen = generation;
    setLoading(true);
    setError(null);
    try {
      const p = await fetchPage(pageNumber);
      if (gen !== generation) return;
      const next = pageNumber === 1 ? p.items : [...items(), ...p.items];
      setItems(() => next);
      // An empty page means the server has nothing more, whatever total says.
      setTotal(p.items.length === 0 ? next.length : p.total);
      setLoaded(pageNumber);
    } catch (e) {
      if (gen === generation) setError(() => e);
    } finally {
      if (gen === generation) setLoading(false);
    }
  }

  const hasMore = () => loaded() > 0 && items().length < total();

  return {
    items,
    total,
    loading,
    error,
    hasMore,
    reset() {
      generation++;
      setItems(() => []);
      setTotal(0);
      setLoaded(0);
      setError(null);
      return load(1);
    },
    loadMore() {
      if (loading() || error() !== null || !hasMore()) return Promise.resolve();
      return load(loaded() + 1);
    },
    retry() {
      return load(loaded() + 1);
    },
  };
}
```

```ts
const FOCUSABLE =
  'a[href], button:not([disabled]), input:not([disabled]), select:not([disabled]), textarea:not([disabled]), [tabindex]:not([tabindex="-1"])';

/** Keeps Tab and Shift+Tab inside a dialog. */
export function trapTab(e: KeyboardEvent, container: HTMLElement) {
  if (e.key !== "Tab") return;
  const items = Array.from(container.querySelectorAll<HTMLElement>(FOCUSABLE));
  if (items.length === 0) return;
  const first = items[0];
  const last = items[items.length - 1];
  const active = document.activeElement;
  const inside = active instanceof Node && container.contains(active) && active !== container;
  if (e.shiftKey && (!inside || active === first)) {
    e.preventDefault();
    last.focus();
  } else if (!e.shiftKey && (!inside || active === last)) {
    e.preventDefault();
    first.focus();
  }
}

export function focusFirst(container: HTMLElement) {
  container.querySelector<HTMLElement>(FOCUSABLE)?.focus();
}

/** Stops the page behind a dialog from scrolling; returns the function that undoes it. */
export function lockScroll(): () => void {
  const previous = document.body.style.overflow;
  document.body.style.overflow = "hidden";
  return () => {
    document.body.style.overflow = previous;
  };
}

export function prefersReducedMotion(): boolean {
  return typeof matchMedia === "function" && matchMedia("(prefers-reduced-motion: reduce)").matches;
}
```

```ts
export function usePageTitle(title: () => string | undefined) {
  createEffect(() => {
    const brand = t("app.name");
    const page = title();
```

```tsx
import { createEffect, Match, on, onCleanup, onMount, Switch } from "solid-js";
import { t } from "../i18n/i18n.ts";
import type { PagedList } from "../lib/paged.ts";
import ErrorState from "./ErrorState.tsx";

/** Loads the next page as the end of the list nears the viewport, and offers a button too. */
export default function LoadMore(props: { list: PagedList<unknown> }) {
  let sentinel!: HTMLDivElement;
  const near = () => sentinel.getBoundingClientRect().top < window.innerHeight + 600;
  const maybeLoad = () => {
    const l = props.list;
    if (l.hasMore() && !l.loading() && l.error() === null && near()) void l.loadMore();
  };
  onMount(() => {
    const io = new IntersectionObserver((entries) => {
      if (entries.some((e) => e.isIntersecting)) maybeLoad();
    }, { rootMargin: "600px 0px" });
    io.observe(sentinel);
    onCleanup(() => io.disconnect());
  });
  // After a page arrives the sentinel can still be on screen, which fires no new intersection.
  createEffect(on(() => props.list.items().length, () => queueMicrotask(maybeLoad), { defer: true }));

  return (
    <div ref={sentinel} class="mt-10 flex min-h-12 justify-center">
      <Switch>
        <Match when={props.list.error() !== null}>
          <ErrorState error={props.list.error()} onRetry={() => void props.list.retry()} />
        </Match>
        <Match when={props.list.loading()}>
          <p role="status" class="text-sm text-silver-ink">{t("common.loading")}</p>
        </Match>
        <Match when={props.list.hasMore()}>
          <button type="button" class="btn btn-outline" onClick={() => void props.list.loadMore()}>
            {t("dresses.load_more")}
          </button>
        </Match>
      </Switch>
    </div>
  );
}
```

```tsx
import { createEffect, createSignal, For, type JSX, on, onCleanup, Show } from "solid-js";
import { i18n, t } from "../i18n/i18n.ts";
import { useCities } from "../lib/cities.ts";
import { focusFirst, lockScroll, trapTab } from "../lib/dom.ts";
import { EMPTY_FILTERS, type Filters } from "../lib/filters.ts";
import { cityName } from "../lib/format.ts";
import { type Color, COLORS, SILHOUETTES, SIZES, SLEEVES } from "../lib/types.ts";
import ColorSwatch from "./ColorSwatch.tsx";
import { CloseIcon } from "./icons.tsx";

interface Choice<T extends string> {
  value: T;
  label: string;
  swatch?: Color;
}

/** One single-choice filter as radio chips, with "Any" first. */
function ChoiceGroup<T extends string>(props: {
  legend: string;
  name: string;
  options: Choice<T>[];
  value: T | null;
  onChange: (v: T | null) => void;
}) {
  const chip = (value: T | null, label: string, swatch?: Color): JSX.Element => (
    <label class="chip">
      <input
        type="radio"
        class="sr-only"
        name={props.name}
        checked={props.value === value}
        onChange={() => props.onChange(value)}
      />
      <Show when={swatch}>{(s) => <ColorSwatch color={s()} />}</Show>
      <span>{label}</span>
    </label>
  );
  return (
    <fieldset>
      <legend class="text-sm font-semibold">{props.legend}</legend>
      <div class="mt-2 flex flex-wrap gap-2">
        {chip(null, t("filters.any"))}
        <For each={props.options}>{(o) => chip(o.value, o.label, o.swatch)}</For>
      </div>
    </fieldset>
  );
}

const priceValue = (n: number | null) => (n === null ? "" : String(n));
const parsePrice = (s: string) => (/^\d+$/.test(s.trim()) ? Number(s.trim()) : null);

/** The bottom sheet with every filter. Changes stay in a draft until "Show dresses". */
export default function FilterSheet(props: {
  open: boolean;
  value: Filters;
  onApply: (f: Filters) => void;
  onClose: () => void;
}) {
  const [draft, setDraft] = createSignal<Filters>({ ...props.value });
  const cities = useCities();
  let panel: HTMLDivElement | undefined;

  createEffect(on(() => props.open, (open) => {
    if (!open) return;
    setDraft({ ...props.value });
    const opener = document.activeElement as HTMLElement | null;
    const unlock = lockScroll();
    queueMicrotask(() => panel && focusFirst(panel));
    onCleanup(() => {
      unlock();
      opener?.focus();
    });
  }));

  const set = <K extends keyof Filters>(key: K, value: Filters[K]) => setDraft((d) => ({ ...d, [key]: value }));

  return (
    <Show when={props.open}>
      <div
        class="fixed inset-0 z-40"
        onKeyDown={(e) => {
          if (e.key === "Escape") props.onClose();
          else if (panel) trapTab(e, panel);
        }}
      >
        <div class="absolute inset-0 bg-ink/40" aria-hidden="true" onClick={() => props.onClose()} />
        <div
          ref={panel}
          role="dialog"
          aria-modal="true"
          aria-labelledby="filters-title"
          tabindex="-1"
          class="sheet-enter outline-none absolute inset-x-0 bottom-0 mx-auto flex max-h-[88vh] max-w-lg flex-col rounded-t-2xl bg-white"
        >
          <div class="flex items-center justify-between border-b border-veil px-5 py-2">
            <h2 id="filters-title" class="text-2xl">{t("filters.title")}</h2>
            <button type="button" class="btn-icon" aria-label={t("common.close")} onClick={() => props.onClose()}>
              <CloseIcon />
            </button>
          </div>

          <div class="flex-1 space-y-6 overflow-y-auto px-5 py-5">
            <label class="block">
              <span class="text-sm font-semibold">{t("filters.city")}</span>
              <select
                class="field-input mt-1"
                value={draft().city}
                onChange={(e) => set("city", e.currentTarget.value)}
              >
                <option value="">{t("filters.any_city")}</option>
                <For each={cities()}>{(c) => <option value={c.slug}>{cityName(c, i18n.lang())}</option>}</For>
              </select>
            </label>

            <fieldset>
              <legend class="text-sm font-semibold">{t("filters.price")}</legend>
              <div class="mt-1 grid grid-cols-2 gap-3">
                <label>
                  <span class="text-xs text-silver-ink">{t("filters.price_min")}</span>
                  <input
                    class="field-input mt-1"
                    inputmode="numeric"
                    value={priceValue(draft().priceMin)}
                    onInput={(e) => set("priceMin", parsePrice(e.currentTarget.value))}
                  />
                </label>
                <label>
                  <span class="text-xs text-silver-ink">{t("filters.price_max")}</span>
                  <input
                    class="field-input mt-1"
                    inputmode="numeric"
                    value={priceValue(draft().priceMax)}
                    onInput={(e) => set("priceMax", parsePrice(e.currentTarget.value))}
                  />
                </label>
              </div>
            </fieldset>

            <ChoiceGroup
              legend={t("filters.size")}
              name="size"
              options={SIZES.map((s) => ({ value: s, label: s }))}
              value={draft().size}
              onChange={(v) => set("size", v)}
            />
            <ChoiceGroup
              legend={t("filters.color")}
              name="color"
              options={COLORS.map((c) => ({ value: c, label: t(`color.${c}`), swatch: c }))}
              value={draft().color}
              onChange={(v) => set("color", v)}
            />
            <ChoiceGroup
              legend={t("filters.style")}
              name="style"
              options={SILHOUETTES.map((s) => ({ value: s, label: t(`silhouette.${s}`) }))}
              value={draft().style}
              onChange={(v) => set("style", v)}
            />

              name="sleeves"

              value={draft().sleeves}
              onChange={(v) => set("sleeves", v)}
            />
          </div>

          <div class="flex gap-3 border-t border-veil px-5 py-3">
            <button
              type="button"
              class="btn btn-quiet"
              onClick={() => setDraft({ ...EMPTY_FILTERS, q: draft().q })}
            >
              {t("filters.reset")}
            </button>
```

```tsx
import { useLocation, useNavigate } from "@solidjs/router";
import { createEffect, createMemo, createSignal, Match, on, Show, Switch } from "solid-js";
import DressGrid from "../components/DressGrid.tsx";
import EmptyState from "../components/EmptyState.tsx";
import ErrorState from "../components/ErrorState.tsx";
import FilterSheet from "../components/FilterSheet.tsx";
import { FilterIcon } from "../components/icons.tsx";
import LoadMore from "../components/LoadMore.tsx";
import SearchBox from "../components/SearchBox.tsx";
import { GridSkeleton } from "../components/Skeleton.tsx";
import { t } from "../i18n/i18n.ts";
import { api } from "../lib/client.ts";
import { countActiveFilters, EMPTY_FILTERS, type Filters, filtersToQuery, parseFilters } from "../lib/filters.ts";
import { createPagedList } from "../lib/paged.ts";
import { usePageTitle } from "../lib/title.ts";

const PER_PAGE = "24";

export default function Dresses() {
  usePageTitle(() => t("dresses.title"));
  const location = useLocation();
  const navigate = useNavigate();
  const filters = createMemo(() => parseFilters(new URLSearchParams(location.search)), EMPTY_FILTERS, {
    equals: (a, b) => filtersToQuery(a).toString() === filtersToQuery(b).toString(),
  });
  const [sheetOpen, setSheetOpen] = createSignal(false);

  const list = createPagedList((page) => {
    const query = filtersToQuery(filters());
    query.set("page", String(page));
    query.set("per_page", PER_PAGE);
    return api.dresses(query);
  });
  createEffect(on(filters, () => void list.reset()));

  const apply = (f: Filters) => {
    setSheetOpen(false);
    const qs = filtersToQuery(f).toString();
    navigate(qs ? `/dresses?${qs}` : "/dresses");
  };
  const active = () => countActiveFilters(filters());
  const firstLoad = () => list.items().length === 0;

  return (
    <div class="pt-8">
      <h1 class="text-4xl">{t("dresses.title")}</h1>
      <div class="mt-6 flex flex-col gap-3 sm:flex-row sm:items-center">
        <div class="flex-1">
          <SearchBox value={filters().q} onSearch={(q) => apply({ ...filters(), q })} />
        </div>
        <button
          type="button"
          class="btn btn-outline"
          classList={{ "border-garnet text-garnet-deep": active() > 0 }}
          aria-haspopup="dialog"
          onClick={() => setSheetOpen(true)}
        >
          <FilterIcon />
          {active() > 0 ? t("dresses.filters_active", { count: active() }) : t("dresses.filters")}
        </button>
      </div>
      <p class="mt-4 min-h-6 text-sm text-silver-ink" aria-live="polite">
        <Show when={!(list.loading() && firstLoad()) && list.error() === null}>{t("dresses.found", { count: list.total() })}</Show>
      </p>

      <div class="mt-4">
        <Switch>
          <Match when={firstLoad() && list.error() !== null}>
            <ErrorState error={list.error()} onRetry={() => void list.retry()} />
          </Match>
          <Match when={firstLoad() && list.loading()}>
            <GridSkeleton />
          </Match>
          <Match when={firstLoad()}>
            <EmptyState title={t("dresses.empty_title")} body={t("dresses.empty_body")}>
              <button type="button" class="btn btn-outline" onClick={() => apply(EMPTY_FILTERS)}>
                {t("dresses.clear")}
              </button>
            </EmptyState>
          </Match>
          <Match when={!firstLoad()}>
            <DressGrid items={list.items()} />
            <LoadMore list={list} />
          </Match>
        </Switch>
      </div>

      <FilterSheet open={sheetOpen()} value={filters()} onApply={apply} onClose={() => setSheetOpen(false)} />
    </div>
  );
}
```

```tsx
import { createSignal, For, onCleanup, onMount, Show } from "solid-js";
import { t } from "../i18n/i18n.ts";
import { lockScroll, prefersReducedMotion, trapTab } from "../lib/dom.ts";
import type { Image } from "../lib/types.ts";
import { ChevronLeftIcon, ChevronRightIcon, CloseIcon } from "./icons.tsx";

/** Full-screen photos: swipe or arrow keys to move, tap the photo to zoom in and pan. */
function PhotoViewer(props: { images: Image[]; start: number; title: string; onClose: () => void }) {
  const [index, setIndex] = createSignal(props.start);
  const [zoomed, setZoomed] = createSignal(false);
  const total = () => props.images.length;
  const label = (i: number) => t("dress.photo", { n: i + 1, total: total() });
  const go = (delta: number) => {
    setZoomed(false);
    setIndex((i) => Math.min(total() - 1, Math.max(0, i + delta)));
    // A nav button that just became disabled drops keyboard focus; keep it in the dialog.
    queueMicrotask(() => {
      const active = document.activeElement;
      if (active instanceof HTMLButtonElement && active.disabled) dialog.focus();
    });
  };
  let dialog!: HTMLDivElement;
  let closeButton!: HTMLButtonElement;
  let touchX: number | null = null;

  onMount(() => {
    const opener = document.activeElement as HTMLElement | null;
    const unlock = lockScroll();
    closeButton.focus();
    onCleanup(() => {
      unlock();
      opener?.focus();
    });
  });

  const onKeyDown = (e: KeyboardEvent) => {
    if (e.key === "Escape") props.onClose();
    else if (e.key === "ArrowLeft") go(-1);
    else if (e.key === "ArrowRight") go(1);
    else trapTab(e, dialog);
  };

  return (
    <div
      ref={dialog}
      role="dialog"
      aria-modal="true"
      aria-label={props.title}
      tabindex="-1"
      class="fixed inset-0 z-50 flex flex-col bg-ink text-white outline-none"
      onKeyDown={onKeyDown}
    >
      <div class="flex items-center justify-between px-3 py-2">
        <span class="text-sm tabular-nums">{label(index())}</span>
        <button
          ref={closeButton}
          type="button"
          class="btn-icon hover:bg-white/10"
          aria-label={t("common.close")}
          onClick={() => props.onClose()}
        >
          <CloseIcon />
        </button>
      </div>
      <div
        class="relative min-h-0 flex-1"
        classList={{ "overflow-auto": zoomed(), "flex items-center justify-center overflow-hidden": !zoomed() }}
        onTouchStart={(e) => {
          touchX = zoomed() ? null : e.touches[0].clientX;
        }}
        onTouchEnd={(e) => {
          if (touchX === null) return;
          const dx = e.changedTouches[0].clientX - touchX;
          touchX = null;
          if (Math.abs(dx) > 50) go(dx < 0 ? 1 : -1);
        }}
      >
        <button
          type="button"
          class="block"
          classList={{ "h-full w-full": !zoomed() }}
          aria-pressed={zoomed()}
          aria-label={t("dress.zoom")}
          onClick={() => setZoomed(!zoomed())}
        >
          <img
            src={props.images[index()].large}
            alt={`${props.title}, ${label(index())}`}
            class={zoomed()
              ? "w-[200%] max-w-none cursor-zoom-out"
              : "mx-auto max-h-full max-w-full cursor-zoom-in object-contain"}
          />
        </button>
      </div>
      <Show when={total() > 1}>
        <div class="flex justify-between px-3 py-2">
          <button
            type="button"
            class="btn-icon hover:bg-white/10"
            disabled={index() === 0}
            aria-label={label(Math.max(0, index() - 1))}
            onClick={() => go(-1)}
          >
            <ChevronLeftIcon class="h-6 w-6" />
          </button>
          <button
            type="button"
            class="btn-icon hover:bg-white/10"
            disabled={index() === total() - 1}
            aria-label={label(Math.min(total() - 1, index() + 1))}
            onClick={() => go(1)}
          >
            <ChevronRightIcon class="h-6 w-6" />
          </button>
        </div>
      </Show>
    </div>
  );
}
```

```tsx
import { createSignal } from "solid-js";
import { t } from "../i18n/i18n.ts";
import { ShareIcon } from "./icons.tsx";

/** Native share sheet on phones; copies the link elsewhere. */
export default function ShareButton(props: { title: string }) {
  const [copied, setCopied] = createSignal(false);

  async function share() {
    const url = location.href;
    if (navigator.share) {
      try {
        await navigator.share({ title: props.title, url });
        return;
      } catch (e) {
        if (e instanceof DOMException && e.name === "AbortError") return;
        // share failed for another reason: fall back to copying
      }
    }
    try {
      await navigator.clipboard.writeText(url);
      setCopied(true);
      setTimeout(() => setCopied(false), 2500);
    } catch {
      prompt(t("dress.share"), url);
    }
  }

  return (
    <span class="inline-flex items-center gap-3">
      <button type="button" class="btn btn-outline" onClick={() => void share()}>
        <ShareIcon />
        {t("dress.share")}
      </button>
      <span role="status" class="text-sm text-silver-ink">{copied() ? t("dress.link_copied") : ""}</span>
    </span>
  );
}
```

```tsx
import { A } from "@solidjs/router";
import { createEffect, createResource, Match, Switch, untrack } from "solid-js";
import DressGrid from "../components/DressGrid.tsx";
import EmptyState from "../components/EmptyState.tsx";
import ErrorState from "../components/ErrorState.tsx";
import { GridSkeleton } from "../components/Skeleton.tsx";
import { t } from "../i18n/i18n.ts";
import { api } from "../lib/client.ts";
import { favorites, MAX_FAVORITES } from "../lib/favorites.ts";
import { usePageTitle } from "../lib/title.ts";
import type { ListItem, Page } from "../lib/types.ts";

export default function Favorites() {
  usePageTitle(() => t("favorites.title"));
  // Fetch once with the ids saved on this device; unhearting here only hides the tile.
  const [page, { refetch }] = createResource((): Promise<Page | null> => {
    const ids = untrack(favorites.ids);
    if (ids.length === 0) return Promise.resolve(null);
    return api.dresses(new URLSearchParams({ ids: ids.join(","), per_page: String(MAX_FAVORITES) }));
  });

  // Ids that the API no longer returns (deleted or unpublished) are dropped silently.
  createEffect(() => {
    const p = page.state === "ready" ? page() : null;
    if (p) untrack(() => favorites.keepOnly(p.items.map((i) => i.id)));
  });

  // Newest favorite first, the same order as on the device.
  const visible = (): ListItem[] => {
    const p = page.state === "ready" ? page() : null;
    if (!p) return [];
    const byId = new Map(p.items.map((i) => [i.id, i]));
    return favorites.ids().flatMap((id) => byId.get(id) ?? []);
  };

  return (
    <div class="pt-8">
      <h1 class="text-4xl">{t("favorites.title")}</h1>
      <div class="mt-6">
        <Switch>
          <Match when={page.error}>
            <ErrorState error={page.error} onRetry={refetch} />
          </Match>
          <Match when={page.loading}>
            <GridSkeleton count={Math.min(favorites.ids().length, 8)} />
          </Match>
          <Match when={visible().length === 0}>
            <EmptyState title={t("favorites.empty_title")} body={t("favorites.empty_body")}>
              <A href="/dresses" class="btn btn-primary">{t("favorites.browse")}</A>
            </EmptyState>
          </Match>
          <Match when={visible().length > 0}>
            <DressGrid items={visible()} />
          </Match>
        </Switch>
      </div>
    </div>
  );
}
```

```ts
import type { AdminShop, ShopInput } from "./types.ts";

export const EMPTY_SHOP_INPUT: ShopInput = {
  name: "", city_id: 0, address: "", phone: "", instagram_url: "", tiktok_url: "", description: "",
  is_published: false, aliases: [],
};

export function shopToInput(s: AdminShop): ShopInput {
  return {
    name: s.name,
    city_id: s.city_id,
    address: s.address,
    phone: s.phone,
    instagram_url: s.instagram_url ?? "",
    tiktok_url: s.tiktok_url ?? "",
    description: s.description ?? "",
    is_published: s.is_published,
    aliases: [...s.aliases],
  };
}

/** Trims every text field and drops blank or repeated aliases (ignoring case) before saving. */
export function cleanShopInput(f: ShopInput): ShopInput {
  const seen = new Set<string>();
  const aliases: string[] = [];
  for (const raw of f.aliases) {
    const alias = raw.trim();
    const key = alias.toLowerCase();
    if (alias && !seen.has(key)) {
      seen.add(key);
      aliases.push(alias);
    }
  }
  return {
    ...f,
    name: f.name.trim(),
    address: f.address.trim(),
    phone: f.phone.trim(),
    instagram_url: f.instagram_url.trim(),
    tiktok_url: f.tiktok_url.trim(),
    description: f.description.trim(),
    aliases,
  };
}

/** Router search params can hold one value or a list; take the first. */
export function firstParam(v: string | string[] | undefined): string {
  return (Array.isArray(v) ? v[0] : v) ?? "";
}
```

```tsx
import { createSignal, Show } from "solid-js";
import { t, tr } from "../../i18n/i18n.ts";
import { uploadImage } from "../../lib/client.ts";
import { errorMessage } from "../../lib/errors.ts";
import type { Image } from "../../lib/types.ts";
import ShopLogo from "../ShopLogo.tsx";

export default function LogoUpload(props: {
  shopId: number;
  name: string;
  logo: Image | null;
  onUploaded: (logo: Image) => void;
}) {
  const [progress, setProgress] = createSignal<number | null>(null);
  const [error, setError] = createSignal<unknown>(null);

  async function pick(input: HTMLInputElement) {
    const file = input.files?.[0];
    input.value = "";
    if (!file) return;
    setError(null);
    setProgress(0);
    try {
      props.onUploaded(await uploadImage(file, { shopId: props.shopId }, setProgress));
    } catch (err) {
      setError(() => err);
    } finally {
      setProgress(null);
    }
  }

  return (
    <div>
      <h2 class="text-sm font-semibold">{t("shopform.logo")}</h2>
      <div class="mt-3 flex flex-wrap items-center gap-4">
        <ShopLogo url={props.logo?.small ?? null} name={props.name || "?"} size="lg" />
        <label class="btn btn-outline cursor-pointer focus-within:outline-2 focus-within:outline-garnet">
          {t("shopform.logo_upload")}
          <input
            type="file"
            accept="image/jpeg,image/png,image/webp"
            class="sr-only"
            disabled={progress() !== null}
            onChange={(e) => void pick(e.currentTarget)}
          />
        </label>
        <Show when={progress() !== null}>
          <span role="status" class="text-sm text-silver-ink">
            {t("photos.uploading", { name: t("shopform.logo"), percent: Math.round((progress() ?? 0) * 100) })}
```

```tsx
export default function Login() {
  usePageTitle(() => t("admin.login_title"));
  const navigate = useNavigate();
  const [search] = useSearchParams();
  const [email, setEmail] = createSignal("");
  const [password, setPassword] = createSignal("");
  const [error, setError] = createSignal<unknown>(null);
  const [busy, setBusy] = createSignal(false);

  // Only return to admin pages, never to another site.
  const next = () => {
    const n = firstParam(search.next);
    return n.startsWith("/admin") && !n.startsWith("/admin/login") ? n : "/admin/shops";
  };

  async function submit(e: SubmitEvent) {
    e.preventDefault();
    setBusy(true);
    setError(null);
    try {
      auth.set(await api.login(email().trim(), password()));
      navigate(next(), { replace: true });
    } catch (err) {
      setError(() => err);
    } finally {
      setBusy(false);
    }
  }

  return (
    <div class="min-h-screen bg-veil">
      <GolBand />
      <main class="mx-auto max-w-sm px-4 py-16">
        <A href="/" class="font-display text-3xl text-garnet">{t("app.name")}</A>

          <h1 class="text-3xl">{t("admin.login_title")}</h1>
```

```ts
export interface DressForm {
  shop_id: number;

  price: string;
  price_is_from: boolean;
  description: string;
  is_published: boolean;

  silhouette: Silhouette | "";

}

  color: "", silhouette: "", sleeves: "", sizes: [],

export function dressToForm(d: AdminDress): DressForm {
  return {
    shop_id: d.shop_id,
    title: d.title,
    price: String(d.price_manat),
    price_is_from: d.price_is_from,
    description: d.description ?? "",
    is_published: d.is_published,
    color: d.color,
    silhouette: d.silhouette,
    sleeves: d.sleeves,
    sizes: [...d.sizes],
  };
}

/**
 * Builds the API input. A blank or non-numeric price becomes 0 and unset enums stay "",
 * so the API answers with the right field errors. Sizes come out in XS…XXL order.
 */
export function dressFormToInput(f: DressForm): DressInput {
  const price = f.price.trim();
  return {
    shop_id: f.shop_id,
    title: f.title.trim(),
    price_manat: /^\d+$/.test(price) ? Number(price) : 0,
    price_is_from: f.price_is_from,
    description: f.description.trim(),
    is_published: f.is_published,
    color: f.color as Color,
    silhouette: f.silhouette as Silhouette,
    sleeves: f.sleeves as Sleeves,
    sizes: SIZES.filter((s) => f.sizes.includes(s)),
  };
}
```

```tsx
import { createStore } from "solid-js/store";
import { t, tr } from "../../i18n/i18n.ts";
import { api, uploadImage } from "../../lib/client.ts";
import { errorMessage } from "../../lib/errors.ts";
import type { Image } from "../../lib/types.ts";
import { ChevronLeftIcon, ChevronRightIcon, PlusIcon, TrashIcon } from "../icons.tsx";

interface Upload {
  key: number;
  name: string;
  progress: number;
  error: unknown;
}

type Action = "earlier" | "later" | "delete";

const ACCEPT = "image/jpeg,image/png,image/webp";

export default function PhotoManager(props: {
  listingId: number;
  title: string;
  images: Image[];
  onChange: (images: Image[]) => void;
}) {
  const [uploads, setUploads] = createStore<Upload[]>([]);
  const [dragging, setDragging] = createSignal<number | null>(null);
  const [dropActive, setDropActive] = createSignal(false);
  const [error, setError] = createSignal<unknown>(null);
  const [status, setStatus] = createSignal("");
  const [working, setWorking] = createSignal(false);
  // Only one change to the photo list at a time, so a rollback can never undo someone else's change.
  const busy = () => working() || uploads.some((u) => u.error === null);
  let list!: HTMLOListElement;
  let fileInput!: HTMLInputElement;
  let nextKey = 0;
  let queue: Promise<void> = Promise.resolve();

  /** Puts keyboard focus back on a photo tile's button after the list has re-rendered. */
  function focusTile(index: number, action: Action) {
    queueMicrotask(() => {
      const tiles = list?.isConnected ? list.querySelectorAll("li") : undefined;
      const tile = tiles?.[Math.min(index, (tiles?.length ?? 1) - 1)];
      const wanted = tile?.querySelector<HTMLButtonElement>(`[data-action="${action}"]`);
      const target = wanted && !wanted.disabled ? wanted : tile?.querySelector<HTMLButtonElement>('[data-action="delete"]');
      (target ?? fileInput)?.focus();
    });
  }

  // One upload at a time keeps memory low on the server's photo resizer.
  function addFiles(files: FileList | null | undefined) {
    for (const file of Array.from(files ?? [])) {
      const key = nextKey++;
      setUploads(uploads.length, { key, name: file.name, progress: 0, error: null });
      queue = queue.then(async () => {
        try {
          const img = await uploadImage(
            file,
            { listingId: props.listingId },
            (p) => setUploads((u) => u.key === key, "progress", p),
          );
          props.onChange([...props.images, img]);
          setUploads((all) => all.filter((u) => u.key !== key));
        } catch (err) {
          setUploads((u) => u.key === key, "error", () => err);
        }
      });
    }
  }

  async function reorder(from: number, to: number, action: Action | null) {
    if (busy() || from === to || to < 0 || to >= props.images.length) return;
    const before = props.images;
    const next = [...before];
    const [moved] = next.splice(from, 1);
    next.splice(to, 0, moved);
    props.onChange(next);
    setError(null);
    setWorking(true);
    try {
      await api.admin.reorderImages(next.map((i) => i.id));
      setStatus(t("photos.moved", { n: to + 1 }));
      if (action) focusTile(to, action);
    } catch (err) {
      props.onChange(before);
      setError(() => err);
      if (action) focusTile(from, action);
    } finally {
      setWorking(false);
    }
  }

  async function remove(img: Image, index: number) {
    if (busy() || !confirm(t("photos.delete_confirm"))) return;
    setError(null);
    setWorking(true);
    try {
      await api.admin.deleteImage(img.id);
      props.onChange(props.images.filter((i) => i.id !== img.id));
      setStatus(t("photos.deleted"));
      focusTile(index, "delete");
    } catch (err) {
      setError(() => err);
      focusTile(index, "delete");
    } finally {
      setWorking(false);
    }
  }

  return (

      <div
        class="rounded-lg border-2 border-dashed p-6 text-center"
        classList={{ "border-garnet bg-blush": dropActive(), "border-silver": !dropActive() }}
        onDragOver={(e) => {
          if (e.dataTransfer?.types.includes("Files")) {
            e.preventDefault();
            setDropActive(true);
          }
        }}
        onDragLeave={(e) => {
          if (!e.currentTarget.contains(e.relatedTarget as Node | null)) setDropActive(false);
        }}
        onDrop={(e) => {
          if (!e.dataTransfer?.files.length) return;
          e.preventDefault();
          setDropActive(false);
          if (!working()) addFiles(e.dataTransfer.files);
        }}
      >
        <p class="text-sm text-silver-ink">{t("photos.drop")}</p>
        <label class="btn btn-primary mt-3 cursor-pointer focus-within:outline-2 focus-within:outline-garnet">
          <PlusIcon />

          <input
            ref={fileInput}
            type="file"
            accept={ACCEPT}
            multiple
            class="sr-only"
            disabled={working()}
            onChange={(e) => {
              addFiles(e.currentTarget.files);
              e.currentTarget.value = "";
            }}
          />
        </label>
      </div>

      <p role="status" aria-live="polite" class="sr-only">{status()}</p>

      <For each={uploads}>
        {(u) => (
          <div class="text-sm">
            <Show
              when={u.error}
              fallback={
                <>
                  <p>{t("photos.uploading", { name: u.name, percent: Math.round(u.progress * 100) })}</p>
                  <progress class="mt-1 w-full accent-garnet" value={u.progress} max={1} />
                </>
              }
            >
              <div role="alert" class="flex items-center gap-3 text-garnet">
                <p class="flex-1">{t("photos.failed", { name: u.name, error: errorMessage(u.error, tr) })}</p>
                <button
                  type="button"
                  class="btn btn-quiet"
                  onClick={() => setUploads((all) => all.filter((x) => x.key !== u.key))}
                >
                  {t("photos.dismiss")}
                </button>
              </div>
            </Show>
          </div>
        )}
      </For>

      <Show when={error()}>
        <p role="alert" class="text-sm text-garnet">{errorMessage(error(), tr)}</p>
      </Show>

      <Show when={props.images.length > 0}>
        <p class="text-sm text-silver-ink">{t("photos.drag_hint")}</p>
        <ol ref={list} class="grid grid-cols-3 gap-3 sm:grid-cols-5">
          <For each={props.images}>
```

```tsx
import { A, useNavigate, useParams, useSearchParams } from "@solidjs/router";
import { createEffect, createResource, createSignal, For, Match, on, Show, Switch } from "solid-js";
import { createStore, reconcile } from "solid-js/store";
import { CheckboxField, FormActions, SelectField, TextArea, TextField } from "../../components/admin/Field.tsx";
import PhotoManager from "../../components/admin/PhotoManager.tsx";
import ErrorState from "../../components/ErrorState.tsx";
import { t, tr } from "../../i18n/i18n.ts";
import { api } from "../../lib/client.ts";
import { fieldMessage, validationFields } from "../../lib/errors.ts";
import { type DressForm, dressFormToInput, dressToForm, EMPTY_DRESS_FORM, firstParam } from "../../lib/forms.ts";
import { usePageTitle } from "../../lib/title.ts";
import { COLORS, SILHOUETTES, SIZES, SLEEVES } from "../../lib/types.ts";

/** The editor for one dress (or a new one); remounted per dress by DressEdit below. */
function DressEditor(props: { id: number | null }) {
  const navigate = useNavigate();
  const [search] = useSearchParams();
  const id = () => props.id;
  const [dress, { mutate }] = createResource(id, (dressId) => api.admin.dress(dressId));
  const [shops] = createResource(() => api.admin.shops());
  const [form, setForm] = createStore<DressForm>({
    ...EMPTY_DRESS_FORM,
    sizes: [],
    shop_id: Number(firstParam(search.shop_id)) || 0,
  });
  // Refill the form only when the saved dress changes, not when just its photos do.
  createEffect(on(() => (dress.state === "ready" ? dress()?.updated_at : undefined), (stamp) => {
    const d = dress.state === "ready" ? dress() : undefined;
    if (stamp && d) setForm(reconcile(dressToForm(d)));
  }));
  const [errors, setErrors] = createSignal<Record<string, string>>({});
  const [error, setError] = createSignal<unknown>(null);
  const [saving, setSaving] = createSignal(false);
  const [saved, setSaved] = createSignal(false);
  const err = (field: string) => errors()[field];
  usePageTitle(() => (id() ? form.title || t("admin.edit") : t("admin.new_dress")));

  async function save(e: SubmitEvent) {
    e.preventDefault();
    setSaving(true);
    setSaved(false);
    setErrors({});
    setError(null);
    try {
      const input = dressFormToInput({ ...form, sizes: [...form.sizes] });
      const current = id();
      const result = current ? await api.admin.updateDress(current, input) : await api.admin.createDress(input);
      setSaved(true);
      if (current) mutate((prev) => ({ ...result, images: prev?.images ?? result.images }));
      else navigate(`/admin/dresses/${result.id}`, { replace: true });
    } catch (e) {
      setErrors(validationFields(e));
      setError(() => e);
    } finally {
      setSaving(false);
    }
  }

  async function remove() {
    const current = id();
    if (!current || !confirm(t("admin.delete_dress_confirm"))) return;
    try {
      await api.admin.deleteDress(current);
      navigate(`/admin/dresses?shop_id=${form.shop_id}`, { replace: true });
    } catch (e) {
      setError(() => e);
    }
  }

  const choose = { value: "", label: t("admin.choose") };
  const shopOptions = () => [
    choose,
    ...(shops.state === "ready" ? shops() ?? [] : []).map((s) => ({ value: String(s.id), label: s.name })),
  ];

  return (
    <div class="max-w-2xl">
      <A href="/admin/dresses" class="text-sm text-silver-ink hover:text-ink">{t("common.back")}</A>
      <h1 class="mt-2 text-3xl">{id() ? form.title || t("admin.edit") : t("admin.new_dress")}</h1>
      <Switch>
        <Match when={dress.error}>
          <ErrorState error={dress.error} />
        </Match>
        <Match when={id() !== null && !dress()}>
          <p class="mt-6 text-silver-ink">{t("common.loading")}</p>
        </Match>
        <Match when={id() === null || dress()}>
          <form class="mt-6 space-y-5 rounded-lg bg-white p-5" novalidate onSubmit={save}>
            <SelectField
              label={t("admin.shop")}
              value={form.shop_id ? String(form.shop_id) : ""}
              options={shopOptions()}
              onChange={(v) => setForm("shop_id", Number(v) || 0)}
              error={err("shop_id")}
            />
            <TextField
              label={t("dressform.title")}
              value={form.title}
              onInput={(v) => setForm("title", v)}
              error={err("title")}
            />
            <div class="grid items-end gap-5 sm:grid-cols-2">
              <TextField
                label={t("dressform.price")}
                inputmode="numeric"
                value={form.price}
                onInput={(v) => setForm("price", v)}
                error={err("price_manat")}
              />
              <CheckboxField
                label={t("dressform.price_is_from")}
                checked={form.price_is_from}
                onChange={(v) => setForm("price_is_from", v)}
              />
            </div>
            <div class="grid gap-5 sm:grid-cols-3">
              <SelectField
                label={t("dressform.color")}
                value={form.color}
                options={[choose, ...COLORS.map((c) => ({ value: c, label: t(`color.${c}`) }))]}
                onChange={(v) => setForm("color", v as DressForm["color"])}
                error={err("color")}
              />
              <SelectField
                label={t("dressform.silhouette")}
                value={form.silhouette}
                options={[choose, ...SILHOUETTES.map((s) => ({ value: s, label: t(`silhouette.${s}`) }))]}
                onChange={(v) => setForm("silhouette", v as DressForm["silhouette"])}
                error={err("silhouette")}
              />
              <SelectField
                label={t("dressform.sleeves")}
                value={form.sleeves}
                options={[choose, ...SLEEVES.map((s) => ({ value: s, label: t(`sleeves.${s}`) }))]}
                onChange={(v) => setForm("sleeves", v as DressForm["sleeves"])}
                error={err("sleeves")}
              />
            </div>
            <fieldset>
              <legend class="text-sm font-semibold">{t("dressform.sizes")}</legend>
              <div class="mt-2 flex flex-wrap gap-2">
                <For each={SIZES}>
                  {(size) => (
                    <label class="chip">
                      <input
                        type="checkbox"
                        class="sr-only"
                        checked={form.sizes.includes(size)}
                        onChange={(e) =>
                          setForm(
                            "sizes",
                            e.currentTarget.checked ? [...form.sizes, size] : form.sizes.filter((s) => s !== size),
                          )}
                      />
                      {size}
                    </label>
                  )}
                </For>
              </div>
              <Show when={err("sizes")}>
                {(e) => <p class="mt-1 text-sm text-garnet">{fieldMessage(e(), tr)}</p>}
              </Show>
            </fieldset>
            <TextArea
              label={t("dressform.description")}
              value={form.description}
              onInput={(v) => setForm("description", v)}
              error={err("description")}
            />
            <CheckboxField
              label={t("admin.published")}
              hint={t("admin.published_hint")}
              checked={form.is_published}
              onChange={(v) => setForm("is_published", v)}
            />
            <FormActions saving={saving()} saved={saved()} error={error()} onDelete={id() ? remove : undefined} />
          </form>

          <section class="mt-8 rounded-lg bg-white p-5">
            <h2 class="text-2xl">{t("photos.title")}</h2>
            <div class="mt-4">
              <Show
                when={id() !== null && dress()}
                fallback={<p class="text-sm text-silver-ink">{t("photos.save_first")}</p>}
              >
                {(d) => (
                  <PhotoManager
                    listingId={d().id}
                    title={d().title}
                    images={d().images}
                    onChange={(images) => mutate({ ...d(), images })}
                  />
                )}
              </Show>
            </div>
          </section>
        </Match>
      </Switch>
    </div>
  );
}
```

```sh
#!/bin/sh
# Renders the PWA icons from icons-src/*.svg with macOS's built-in Quick Look (qlmanage).
# Re-run after changing an SVG; the PNGs are committed so builds need no image tools.
set -eu
cd "$(dirname "$0")/.."
out=public/icons
tmp=$(mktemp -d)
mkdir -p "$out"

render() { # source.svg size output.png
  qlmanage -t -s "$2" -o "$tmp" "$1" >/dev/null 2>&1
  mv "$tmp/$(basename "$1").png" "$out/$3"
}

render icons-src/icon.svg 512 icon-512.png
render icons-src/icon.svg 192 icon-192.png
render icons-src/icon.svg 180 apple-touch-icon.png
render icons-src/maskable.svg 512 maskable-512.png
cp icons-src/icon.svg public/favicon.svg
rm -rf "$tmp"
echo "icons written to $out"
```
